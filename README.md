# FAOSTAT Wheat Regression

## Objective
To predict wheat yield using FAOSTAT data.

## Dataset
FAOSTAT wheat crop data.

## Models Used
- Linear Regression
- Polynomial Regression
- Multivariate Regression

## Train-Test Split
70% training data
30% testing data

## Evaluation Metrics
- MSE
- RMSE
- MAE
- R²

## Features
- Year
- Production
- Area harvested

## Target
- Wheat Yield
